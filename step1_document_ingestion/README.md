# RAG 第一步：解析整本研究生手册

这次的处理范围是整本 PDF，不是某一个问题或某一项制度。

## 结果

- PDF 共 228 个物理页。
- 前 6 页为封面和目录。
- 正文纸面页码为 1-222 页。
- 根据目录拆分为 30 份独立文件记录。
- 每份记录保留标题、类别、来源、纸面页码、PDF 页码、逐页正文和合并正文。

## 文件说明

- `extract_full_handbook.py`：完整提取脚本。
- `handbook_documents.jsonl`：主要数据集，一行代表一份制度。
- `manifest.json`：30 份制度的清单、页码范围和字符数，便于人工核对。

## 为什么使用 JSONL

后续的切分、向量化和检索都应以“独立制度”为基本边界。JSONL 可以逐条读取，不需要一次把整本手册载入内存，也方便发现某一份制度的解析错误后单独重建。

## 重新运行

```powershell
python .\extract_full_handbook.py "研究生手册.pdf" .
```

当前阶段只完成“整本 PDF -> 30 份结构化制度”。下一阶段才会把每份制度继续切成较小的知识块。
